# seminarios324

Repositorio para alojar la página web de los seminarios de becarios organizados por la oficina 324 de FAMAF, UNC.

Aquí encontrarás información sobre los próximos seminarios, así como archivos y recursos de seminarios anteriores.

![Flyer](https://nicolasvazquez95.github.io/seminarios324/assets/flyer1.png)

## Sitio web

Anteriormente, el sitio web fue construido con [Jekyll](https://jekyllrb.com/) y alojado en GitHub Pages. En 2026, hicimos una mudanza a [Quarto](https://quarto.org/).

Puedes ver la versión en línea del sitio web en [https://nicolasvazquez95.github.io/seminarios324/](https://nicolasvazquez95.github.io/seminarios324/).

## Cómo contribuir

La rama main contiene la versión en línea del sitio web.
Para contribuir, por favor crea una nueva rama desde main, realiza tus cambios y luego abre un pull request para revisión. Antes de fusionar, asegúrate de que tu código sigue las convenciones del proyecto y que el sitio web se ve según lo esperado.

### Estructura del proyecto

- `index.qmd`: Página principal del sitio web.
- `posts/`: Carpeta que contiene las publicaciones de los seminarios.
- `about.qmd`: Página con información sobre el propósito del sitio web y su creador.
- `archivo.qmd`: Página que lista todos los seminarios pasados.
- `assets/`: Archivos estáticos como CSS, JavaScript e imágenes.
- `_quarto.yml`: Archivo de configuración para Quarto.
- `old_web/`: Carpeta que contiene la versión anterior del sitio web construido con Jekyll.
- `README.md`: Este archivo de documentación.
